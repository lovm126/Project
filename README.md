项目名称：建筑能耗研究 LLM-Wiki 个人知识库
我是一名建筑能耗与节能方向的研究生。传统的论文管理方式（收藏夹、文件夹）无法实现知识点的交叉引用和深度综合。受Andrej Karpathy "LLM as a wiki builder" 方法论启发，我搭建了一套 AI 驱动的学术知识库系统。
技术栈：Claude Code + MiMo API（推理层）+ Obsidian（展示层）+ PyMuPDF（图表提取）+ LaTeX 公式识别
工作流程：
 1. 论文 PDF 放入 raw/papers/ 目录
 2. AI 全文阅读，提取核心观点
 3. 自动提取论文中的图表（像素级裁剪）和公式（LaTeX 编码）
 4. 结构化生成：来源摘要页、概念页、实体页、对比分析页
 5. 构建双向链接网络，生成全局索引
 当前状态：知识库刚建立，已收录 3 篇论文（EnergyPlus 建筑负荷实时预测系统、建筑隔热材料、可再生能源），已产出 15+结构化知识页面。每篇论文 ingest 约 5-8 万 tokens，月需求 500-1000 万 tokens，将持续扩展。
